# Stack

Python 3.12, Flask 3.1.3, HTML/CSS/JavaScript sem framework de frontend. TensorFlow 2.21.0 é opcional, carregado apenas pelo CLI de treinamento ou configuração explícita de modelo. Tokenização NFKD compartilhada usa somente a biblioteca padrão; NLTK e seus downloads foram removidos do fluxo.

requirements.lock contém a base web; requirements-ml.lock inclui treinamento e inferência. Instalação binária com hashes verificados no PyPI. DM Sans e Space Grotesk são locais com suas licenças OFL.
