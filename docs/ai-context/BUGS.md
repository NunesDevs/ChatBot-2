# Correções e limites

Corrigidos: dependências incompatíveis com Python 3.12, modelo obrigatório ausente, downloads NLTK ao importar, treinamento durante requisição, edição sem autorização, divergência de vocabulário, renderização HTML de mensagens e documentação que prometia aprendizado automático.

O matcher não é um modelo generativo. A métrica de treino não comprova qualidade em perguntas novas. Bases pequenas podem produzir confiança neural inadequada; padrões exatos têm prioridade, baixa confiança/ambiguidade usam resposta de fallback. Modelos ficam obsoletos após editar a base e deixam de ser usados até novo treinamento. Sem hospedagem pública configurada.
